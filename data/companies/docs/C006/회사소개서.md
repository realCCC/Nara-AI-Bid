# 온누리기획 주식회사 회사소개서

1. 회사 개요
- 온누리기획은 2014년 부산에서 설립된 공공사업 운영 대행사로 지원사업 사무국 운영과 정책 홍보 캠페인을 수행합니다.
- 비전: 공공사업의 현장 실행력을 높이는 운영 파트너.

2. 보유 인증 및 면허
- 직접생산확인증명서 (행사대행업, 광고대행업)
- 여성기업확인서 (중소벤처기업부)

3. 핵심 인력
- 사무국장 정유나 팀장: 창업지원사업 사무국 운영 경력 9년, 참여기업 모집·선정·사후관리 총괄.
- 사업운영담당 7명: 접수, 평가위원회 운영, 정산 검토 담당.
- 홍보담당 3명: SNS 채널 운영, 보도자료 작성, 캠페인 콘텐츠 제작.

4. 주요 실적 상세
- 지역 창업지원사업 사무국 운영 (1.3억 원): 참여기업 85개사 모집·선정, 정산 오류 0건, 만족도 4.4점.
- 공공기관 정책 홍보 캠페인 대행 (0.7억 원): SNS 도달 120만 회, 오프라인 캠페인 6회.

5. 수행 방법론
- 사무국 개소 → 공고·모집 → 선정평가 → 협약·지원 → 점검·정산 → 성과관리 순서로 운영합니다.
- 전용 접수·문의 창구와 업무 매뉴얼을 운영해 담당자가 바뀌어도 동일한 품질을 유지합니다.
