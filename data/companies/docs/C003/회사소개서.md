# 코드브릿지 주식회사 회사소개서

1. 회사 개요
- 코드브릿지는 2016년 경기도에서 설립된 공공 SW 개발 전문기업으로 업무 플랫폼 구축, 시스템 유지관리, 데이터 포털 고도화를 수행합니다.
- 비전: 공공 서비스를 더 쉽게 쓰도록 만드는 사용자 중심 디지털 전환.

2. 보유 인증 및 면허
- 소프트웨어사업자 신고 (한국소프트웨어산업협회)
- 직접생산확인증명서 (정보시스템개발서비스, 패키지소프트웨어개발 및 도입서비스)
- GS인증 1등급 제품 1종 보유, ISO 9001 품질경영시스템 인증
- 벤처기업 확인 (2020년)

3. 핵심 인력
- 총괄 PM 최준혁 상무: 정보처리기술사, 공공 SI PM 경력 16년.
- 데이터 아키텍트 한지민: 공공데이터 개방 포털 고도화 설계 담당, 데이터 엔지니어 4명 리드.
- 개발자 18명은 전자정부 표준프레임워크 기반 개발 경험을 보유합니다.

4. 주요 실적 상세
- 공공기관 업무 플랫폼 구축 (4.2억 원): 결재·문서·민원 통합 플랫폼, 사용자 1,500명.
- 행정정보시스템 유지관리 (1.8억 원): 장애 처리 평균 2시간 이내, 가용률 99.9% 유지.
- 공공데이터 개방 포털 고도화 (2.6억 원): Open API 120종 정비, 데이터 품질 진단 수행.

5. 수행 방법론
- 착수 → 요구사항 분석 → 설계 → 개발 → 시험 → 이행·안정화 단계로 수행하며 산출물은 행정기관 SW 사업관리 지침을 따릅니다.
- 2주 단위 스프린트와 주간 진척 보고로 일정을 관리하고, 시큐어코딩 점검과 웹 접근성 검사를 개발 단계마다 실시합니다.

6. 차별화 포인트
- 구축과 유지관리를 모두 수행해 운영 단계까지 고려한 설계가 가능합니다.
