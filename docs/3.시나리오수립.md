# 핵심 사용자 시나리오 및 워크플로우

입찰 담당자의 반복 업무를 돕는 2가지 시나리오를 정의합니다. **메인은 SC-001(공고 추천)**, SC-002(제안서 초안 템플릿)는 연결 기능입니다. 설계 세부는 4번 문서를 봅니다.

## 페르소나

- **누구**: 공공 용역 입찰에 참여하는 중소기업 입찰·영업 담당자
- **수준**: 비전공자지만 엑셀·JSON과 웹 화면 필터는 다룰 수 있음 (Mid-Tech)
- **Pain Point**: 공고 탐색에 시간이 많이 듦 / 공고마다 분석·초안 작성 반복 / 담당자마다 품질 편차

---

## SC-001: 업체 맞춤 추천 공고를 근거와 함께 검토하고 입찰할 공고 선택하기 (메인)

**목표**: 자격 확인·1차 선별은 룰이, 공고서 검토·순위는 RAG가 하고 담당자는 검토와 최종 선택만 한다.

### 흐름

| 단계 | 담당자 | 시스템 | 출력 |
|---|---|---|---|
| 1. 입력 | 업체 JSON 업로드 | 스키마 검증, 공고 500건 로드 | 업체 프로필 |
| 2. 하드 필터 | "추천 시작" 클릭 | 룰로 탈락 공고 제거 (아래 표) | 후보 + 제외 사유 |
| 3. 소프트 점수 | 대기 | 룰로 0-100점 → 상위 10건 | 상위 10건 + 항목별 점수 |
| 4. RAG 추천 | 대기 | 10건 PDF 청킹·검색 → LLM 순위·근거 | 순위 + 근거 3-4개(출처) |
| 5. 선택 (HITL ①) | 10건 검토 후 1건 선택 | 근거·인용 표시 | 선택 공고 |
| 6. 전환 | "제안서 만들기" | State 저장 후 SC-002로 | - |

**하드 필터 규칙** (하나라도 걸리면 제외)

| 규칙 | 조건 |
|---|---|
| H1 PDF 보유 | 첨부 중 PDF가 1개 이상 (500건 중 437건 통과) |
| H2 마감일 | 테스트 데이터라 **미적용** |
| H3 업종 | 공고 대분류/세부분류가 업체 업종에 포함 |
| H4 참가 제한 | 중소기업 제한 공고면 업체가 중소기업 |
| H5 지역 제한 | 수동 매핑표의 허용 시·도에 업체 소재지 포함 |
| H6 예산 | 공고 예산이 업체 참여 가능 금액 범위 안 |

**소프트 점수** = 업종 세부 일치 35% + 공고명·역량 키워드 겹침 30% + 예산·실적 규모 유사도 20% + 선호 계약방식 15% (초기 설정값)

**RAG 추천**: 10건 PDF를 청킹 → BGE-M3 임베딩·Chroma 저장 → 업체 역량 + 고정 질의(참가자격, 과업 내용, 평가 방법)로 검색 → LLM이 순위와 근거 생성. 근거마다 출처(PDF 파일·페이지·인용 또는 필드 값)를 붙인다. 출력 검증에 실패하면 룰 점수 순위로 대체한다.

> 한계: PDF 보유 437건 중 제안요청서까지 PDF인 공고는 63건뿐이라, 나머지는 근거가 참가자격·사업 개요 수준에 그친다.

### 입력 예시 (업체 JSON)

```json
{
  "업체ID": "C041", "회사명": "디지털배움 주식회사", "중소기업여부": true, "소재지": "서울",
  "업종": {"대분류": ["교육 및 전문직종/기술서비스"], "세부분류번호": ["86101696"]},
  "참여가능금액": {"최소": 30000000, "최대": 300000000},
  "역량키워드": ["교육", "방과후", "코딩", "AI", "연수"],
  "선호계약방식": ["제한경쟁"],
  "보유인력": {"전임강사": 12, "프로젝트매니저": 2},
  "과거실적": [{"프로젝트명": "교원 대상 AI·디지털 역량 연수", "계약금액": 62000000, "키워드": ["AI", "연수"]}]
}
```

### 기대 출력 (형식 예시)

| 순위 | 공고명 | 예산 | 룰 점수 |
|---|---|---|---|
| 1 | 2026 강동송파 중등 학교로 찾아가는 AI·디지털 기반 교육혁신 연수 | 9,081만 | 96 |
| 2 | AI·코딩 드론 미래 인재 양성 프로젝트 운영 | 5,000만 | 78 |
| 3 | 2026년 교육훈련 위탁운영 용역 | 1.1억 | 76 |

**1순위 추천 근거 예시**
- 과업 일치: 교원 대상 AI·디지털 연수 → 업체 연수 실적과 같은 유형 (공고문.pdf p.1 인용)
- 업종 일치: 세부분류 86101696 (공고·업체 필드)
- 규모 적합: 예산 9,081만 원 ≈ 실적 평균 (필드)

## SC-002: 선택한 공고의 제안서 초안 템플릿 받기 (연결 기능)

**목표**: 완성형 제안서가 아니라 담당자가 이어서 쓸 **골격**을 만든다. LLM은 평가항목 추출에만 쓰고 문장은 생성하지 않는다.

### 흐름

| 단계 | 시스템 | 출력 |
|---|---|---|
| 1. 입력 | SC-001 결과(공고·업체·근거·PDF 청크)를 State에서 로드 | - |
| 2. 평가항목 추출 | PDF 청크 검색 → LLM이 평가항목·배점·과업기간을 JSON으로 추출 (원문에 없으면 null, 출처 표시) | 평가항목 JSON |
| 3. 템플릿 생성 | 고정 HTML 템플릿에 값 삽입 (LLM 미사용) | 섹션 4개 |
| 4. 대응표 | 평가항목·배점·대응 섹션·업체 근거를 표로 삽입 | 대응표 |
| 5. 다운로드 | 미리보기 → `.html` 다운로드 → 담당자가 `[확인 필요]` 작성 | HTML 파일 |

| 섹션 | 삽입하는 값 | `[확인 필요]`로 남기는 곳 |
|---|---|---|
| 회사소개 | 회사명, 역량, 인증, 실적 | 비전·차별화 |
| 수행방안 | 평가항목을 목차로 + 항목별 업체 근거 | 수행 방안 본문 |
| 추진일정 | 고정 단계 + 과업기간 | 단계별 기간 |
| 조직구성 | 역할별 보유 인원 | 투입 인력 |
| 평가기준 대응표 | 평가항목·배점·출처·대응 섹션 | 추출 실패 항목 |

## KPI 종합

| 우선순위 | KPI | 목표 | 측정 방법 | 판정 |
|---|---|---|---|---|
| **1순위** | 추천 정확도 | Hit Rate@3 80%↑ (10개 중 8개) + Precision@3 0.67↑ | 100조합 라벨과 RAG 상위 3건 비교. 룰 순위와도 비교해 RAG 효과 확인 | 자동 |
| **1순위** | 자격 필터 정확성 | 부적격 0건 | 규칙 단위 테스트 + 샘플 30건 대조 + 라벨 집계 | 자동 |
| **1순위** | 근거 설명 가능성 | 출처 확인 95%↑ | 인용 문구·필드 값 원문 대조 | 자동 |
| 업무 | 시간 단축 | 50%↑ (SC-001+002 합산) | 대표 공고 3건 수작업 vs 서비스 | 사람 |
| 보조 | 초안 시작 가능 | 10건 생성 + 반영률 100% | HTML 자동 검사 | 자동 |
| 보조 | 초안 근거성 | 없는 사실 0건 | 프로필·공고서 원문 대조 | 자동 |
| 보조 | 담당자 만족도 | 3.5/5점↑ | 5점 척도 + 인터뷰 | 사람 |

- **Hit Rate@3**: 상위 3건에 '추천' 공고가 1건 이상 있는 업체 비율 (담당자는 1건만 고르므로)
- **Precision@3**: 상위 3건 중 '추천' 비율 평균 (나머지 2건의 품질 보완)

### 정답 라벨 기준

평가용 업체 10개(41-50) × 시스템 상위 10건 = **100조합**만 담당자 1인이 라벨링합니다.

| 라벨 | 기준 |
|---|---|
| 부적격 | 자격(필드 또는 공고서) 하나라도 미충족 |
| 추천 | 자격 충족 + 과업 일치 + 유사 실적 1건↑ + 규모 적합(예산 ≤ 최대 실적 2배) |
| 적격-비추천 | 자격은 되지만 위 조건 중 하나 이상 미충족 |

**편향 방지**: ① 순위를 가리고 라벨링 ② RAG 실행 전에 라벨 커밋 ③ 가중치 고정 후 라벨링 ④ 조정은 업체 01-05로만, 평가는 41-50으로만

## 우선순위

| 시나리오 | 가치 | 난이도 | 비고 |
|---|---|---|---|
| **SC-001 (메인)** | 매우 높음 | 중간 | 구현·검증 시간 우선 배분 |
| SC-002 (연결) | 중간 | 낮음 | 템플릿이 동작하는 수준에서 멈추고 남는 시간은 추천 개선에 사용 |

**최종 검증(Gate)**: 평가용 업체 5개로 업로드 → 추천 → 선택 → 초안 다운로드 E2E 테스트, 1순위 KPI 3종 달성 필수.
