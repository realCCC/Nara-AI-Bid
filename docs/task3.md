# 핵심 사용자 시나리오 및 워크플로우

## 사전 정보: 사용자 페르소나 (Mid-Tech 담당자)

### 대상 사용자
- **직무:** 입찰·영업 담당자 (중소 IT 기업)
- **기술 수준:** Mid-Tech (기술 비전공자, 하지만 기본 데이터 이해 가능)
- **특징:** 엑셀/JSON 파일 다룰 수 있음, UI 기본 필터/옵션 이해 가능

### 사용자의 Pain Point
- 매일 아침 100-200건의 공고 중 1-2건만 찾음 (2-3시간 소비)
- 공고 분석과 제안서 초안 작성이 반복 업무
- 담당자 경험에 따라 품질 편차 큼

## 시나리오 1: 공고 추천 및 적합성 분석

### ID
SC-001

### 시나리오명
"우리 회사에 맞는 입찰 공고 찾기"

### 상황
입찰담당자가 아침에 출근해서 매일 100-200개 공고 중 자사 역량과 맞는 것을 찾는데 2-3시간 소비. 수작업으로 진행해서 기회를 놓치는 경우가 많음.

### 목표
- **현재:** 자사 역량에 맞는 공고를 수작업으로 하루에 1-2건만 발굴
- **기대:** AI 추천으로 3-5건의 적합 공고를 5분 내에 추천받기 + 각 공고별 낙찰 가능성 분석
- **핵심 메리트:** 
  - 효율성: 같은 시간에 공고 검토 수량 5배 증가 (5건 → 25건/월)
  - 의사결정: 낙찰 가능성 높은 공고만 선별
  - 결과: 양(수량) + 질(선별) 결합 → 수주 기회 극대화

### 사전 조건
- 업체 프로필 정보 등록 완료 (기술 역량, 보유 인력, 과거 실적)
- 현재 진행 중인 공고 데이터가 시스템에 로드됨 (20-30개)

### 상세 흐름

| 단계 | 사용자 행동 | 시스템 동작 | 비고 |
|------|-----------|-----------|------|
| 1 | 대시보드 "공고 추천" 탭 진입 | 대시보드 준비 | 1-2초 |
| 2 | JSON 파일 업로드 | 파일 파싱 및 검증 | 기업 프로필 확인 |
| 3 | 필터 선택 (선택사항) | 필터 조건 적용 | 예산, 지역, 분야 |
| 4 | "추천 공고 조회" 클릭 | 유사도 계산 → 결과 표시 | **5초 내 완료** |
| 5 | 추천 공고 확인 | 상위 5건 테이블 표시 | 공고명, 예산, 적합도 |
| 6 | 공고 1건 선택 | 상세정보 + 매칭 분석표 표시 | 필수자격 충족도 |
| 7 | "제안서 만들기" 클릭 | SC-002로 전환 | 세션 유지 |

## 시나리오 2: 제안서 초안 자동 생성 및 검토

### ID
SC-002

### 시나리오명
"선택된 공고에 대한 제안서 초안 만들고 수정하기"

### 상황
입찰 담당자가 적합한 공고를 선택했음. 이제 제안서를 작성해야 하는데, 공고마다 2-3시간 소비. 회사소개, 기술방안, 조직구성 등을 매번 처음부터 작성하고 공고별로 포맷/스타일이 달라서 일관성 없음.

### 목표
- **현재:** 공고별로 제안서 초안 작성에 2-3시간 소비
- **기대:** AI가 초안 생성 (5분) → 담당자 검토/수정 (30분)으로 단축
- **핵심 메리트:**
  - 효율성: 제안서 작성 시간 70% 감축 (2-3시간 → 35분)
  - 품질: 공고별 맞춤형 작성 + 평가기준 최적화
  - 의사결정: 평가기준 대응 전략 제시로 강화 방향 명확화
  - 결과: 더 많은 공고에 제안 가능 + 각 제안서 경쟁력 향상

### 사전 조건
- SC-001에서 특정 공고 선택 완료
- 업체 프로필 정보 시스템에 등록됨
- 선택된 공고의 상세 정보(과업내용, 평가기준, 필수자격) 준비됨

### 상세 흐름

| 단계 | 사용자 행동 | 시스템 동작 | 비고 |
|------|-----------|-----------|------|
| 1 | "제안서 만들기" 클릭 | 공고 ID + 기업정보 전달 | SC-001에서 연계 |
| 2 | 프로그레스 바 확인 | 공고 분석 Agent 실행 | 1-2초 |
| 3 | 초안 생성 중... | 4개 섹션 병렬 생성 | **5분 내 완료** |
| 4 | 초안 생성 완료 알림 | 마크다운 + 매핑표 표시 | 에디터에서 편집 가능 |
| 5 | 부족한 부분 수정 (선택) | 실시간 미리보기 | 스타일 체크 표시 |
| 6 | "다운로드" 클릭 | Markdown/Word/PDF 선택 | 담당자가 외부 편집 가능 |
