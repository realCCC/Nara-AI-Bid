# 나라장터 AI 입찰 어시스턴트 - 문제 정의 및 서비스 기획

## 1. 한 줄 요약

**업체 정보를 넣으면 공고 500건 중 맞는 공고 10건을 골라 근거와 함께 추천하고, 선택한 공고로 제안서 초안 템플릿을 만들어 주는 서비스**

- **메인**: 기업 맞춤 공고 추천 (어떤 공고를, 왜 추천하는지)
- **보조**: 제안서 초안 템플릿 (고정 템플릿 + 값 삽입. 본문은 담당자가 작성)
- **데이터**: 실제 용역 공고 500건(공공데이터포털, 2026-05 공고분, 공고서 PDF 포함) + 가상 업체 50건
- 조달청 API 실시간 연계는 고도화 단계로 미룸

## 2. 문제 정의

| 구분 | 내용 |
|---|---|
| 현재 | 담당자가 매일 올라오는 공고를 일일이 보고, 자격·평가기준을 손으로 정리하고, 제안서를 매번 처음부터 작성 |
| 시간 손실 | 처리할 수 있는 공고 수가 제한되어 적합한 공고를 놓침 |
| 품질 편차 | 담당자마다 판단 기준·제안서 품질이 다르고, 필수 항목 누락이 생김 |
| 기회 비용 | 반복 업무에 묶여 수주 기회와 전략 업무를 놓침 |

**기회 요인**: 공고의 업종·참가 제한·지역·예산은 정형 필드라 **룰**로 판단할 수 있고, 과업 내용·평가기준은 공고서 PDF에만 있어 **RAG**로 읽을 수 있다.

## 3. 목표 사용자

공공 용역 입찰에 참여하는 중소기업(IT·교육·연구조사·행사 등)의 입찰·영업 담당자. 서비스는 담당자의 판단을 대체하지 않고 정보를 빠르고 일관되게 제공하는 조력자다.

## 4. 추천 구조 (3단계)

| 단계 | 질문 | 방식 | 결과 |
|---|---|---|---|
| ① 하드 필터 | 입찰에 참여할 수 있는가? | 룰: PDF 보유, 업종, 참가 제한, 지역 제한, 예산 범위 | 탈락 공고 + 사유 |
| ② 소프트 점수 | 검토할 가치가 있는가? | 룰: 업종 세부 일치, 키워드 겹침, 예산 규모, 계약방식 → 0-100점 | 상위 10건 |
| ③ RAG 추천 | 무엇을 먼저 볼까? | 10건의 공고서 PDF만 청킹·임베딩 → LLM이 순위·근거 생성 | 순위 + 근거 3-4개(출처 포함) |

500건 전체를 LLM으로 읽지 않고 룰로 10건까지 줄이므로, 비용이 업체당 10건 분량으로 고정되고 ①②는 항상 같은 결과가 나온다.

## 5. 핵심 기능

| 구분 | 기능 |
|---|---|
| **필수** | ① 기업 맞춤 공고 추천 (위 3단계) ② 담당자가 추천 공고 1건 선택 (Human-in-the-loop) ③ 제안서 초안 템플릿 생성 |
| **축소** | 제안서는 고정 템플릿 + 값 삽입. LLM은 공고서에서 평가항목·배점 추출에만 사용. 채울 수 없는 곳은 `[확인 필요]`. 마감일 필터는 테스트 데이터라 미적용 |
| **확장** | 조달청 API 연계, HWP 파싱, 제안서 본문 LLM 생성, 자동 검증·재작성 루프, PDF/Word 내보내기 |

**제안서 초안 템플릿 구성**: 회사소개 / 수행방안(평가항목을 목차로) / 추진일정 / 조직구성 + 평가기준 대응표 → HTML 다운로드

## 6. KPI

| 우선순위 | KPI | 목표 | 측정 |
|---|---|---|---|
| **1순위** | 추천 정확도 | Hit Rate@3 80% 이상 + Precision@3 0.67 이상 | 평가용 업체 10개 × 상위 10건 = 100조합에 사람이 라벨(부적격/적격-비추천/추천) |
| **1순위** | 자격 필터 정확성 | 필터 통과 공고 중 부적격 0건 | 규칙 단위 테스트 + 샘플 30건 대조 |
| **1순위** | 근거 설명 가능성 | 출처 확인 95% 이상 | 인용 문구·필드 값을 원문과 자동 대조 |
| 업무 | 시간 단축 | 50% 이상 | 대표 공고 3건 수작업 vs 서비스 실측 |
| 보조 | 초안 시작 가능 | 10건 생성 + 필수 항목 반영 100% | 자동 검사 |
| 보조 | 초안 근거성 | 프로필·공고서에 없는 사실 0건 | 자동 대조 |

- 모든 KPI는 Phase 4(7-8주차)에 측정. 목표치는 팀 설정값, 시간 수치는 실측으로 확정한다.
- 25,000조합(500×50)을 다 라벨링할 수 없어 **시스템 상위 10건에만** 라벨을 붙인다.

## 7. 범위 및 제약

| In Scope | Out of Scope |
|---|---|
| 공고 500건 파일, 가상 업체 50건 | 조달청 API 실시간 연계, 마감일 필터 |
| 룰 필터·점수 + RAG 추천 + HITL 선택 | HWP 공고서 파싱 |
| 제안서 HTML 초안 템플릿 | 완성형 제안서, Word/PDF 변환 |
| React 화면 + LangGraph Server + Docker | 자동 제출, 낙찰가 예측, 프로덕션 보안 |

**주요 제약**
- **데이터**: 500건 중 PDF 보유 437건만 추천 대상. 지역 제한 필드에 지역명이 없어 45건은 수동 매핑
- **보안**: 실제 고객 정보 대신 가상 데이터 사용, 공고의 담당자 연락처(PII)는 제거
- **안전**: HTML은 sanitize 후 표시 (XSS 방지)
- **일정**: 8주(하루 1-2시간). 기능 1-3 필수, 자동 검증 루프는 2차 목표
